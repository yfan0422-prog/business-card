# 名片管理系统设计文档

**日期**: 2026-05-09
**版本**: v1.0 (MVP)
**作者**: 用户需求分析

---

## 1. 项目概述

### 1.1 背景
用户收到大量名片，需要一个简单、免费、私有化的名片管理系统，支持快速录入和智能检索。

### 1.2 目标
- 随时随地通过企业微信录入名片
- 快速检索个人和公司信息
- 所有数据存储在本地群晖NAS上
- 检索结果以名片卡片图片形式展示

### 1.3 约束条件
- 部署在群晖DS923+ NAS上（AMD双核，4GB内存）
- 使用企业微信作为用户界面
- 第一阶段手动录入，后续添加OCR
- 使用火山方舟API实现AI智能搜索（第二阶段）

## 4. 功能需求

### 4.1 第一阶段（MVP）功能

#### 4.1.1 名片录入
- 用户发送名片照片给企业微信机器人
- 机器人分步骤引导用户输入信息：
  1. 姓名
  2. 公司
  3. 部门
  4. 职位
  5. 手机
  6. 电话
  7. 邮箱
  8. 地址
  9. 备注
- 可选上传头像照片
- 录入完成后生成名片卡片图片并返回

#### 4.1.2 名片检索
- **按姓名搜索**: 输入"搜索张三"或"张三"
- **按公司搜索**: 输入"搜索某某公司"
- **全文搜索**: 在所有字段中搜索关键词
- **搜索结果**: 生成名片卡片图片，包含：
  - 头像
  - 个人完整信息
  - 名片照片缩略图
  - 备注
  - 同公司联系人列表

#### 4.1.3 公司搜索
- 输入公司名称，返回：
  - 公司信息
  - 所有联系人列表（按部门分组）
  - 简单的组织架构文本展示

#### 4.1.4 基础管理
- 编辑已有联系人信息
- 删除联系人
- 查看最近录入的名片列表

### 4.2 第二阶段功能
- OCR自动识别名片信息（EasyOCR）
- 火山方舟AI智能语义搜索
- 公司信息自动从网络获取

### 4.3 第三阶段功能
- 人脸识别匹配
- 可视化组织架构图
- 网页管理界面

## 6. 企业微信交互设计

### 6.1 命令列表

| 命令 | 说明 |
|------|------|
| help / 帮助 | 显示帮助信息 |
| search [关键词] / 搜索 [关键词] | 搜索名片 |
| list / 列表 | 显示最近录入的名片 |
| new / 新增 | 开始录入新名片 |
| edit [姓名] / 编辑 [姓名] | 编辑联系人 |
| delete [姓名] / 删除 [姓名] | 删除联系人 |
| company [公司名] / 公司 [公司名] | 查看公司信息 |

### 6.2 交互流程

#### 录入流程
```
用户：[发名片照片]

机器人：收到名片照片！开始录入信息。
请输入姓名：

用户：张三

机器人：好的，姓名：张三
请输入公司名称：

用户：某某科技有限公司

机器人：好的，公司：某某科技有限公司
请输入部门（可选）：

...（依次收集所有信息）...

机器人：是否上传头像照片？（回复照片或"跳过"）

用户：[发头像照片] / 跳过

机器人：录入完成！
[生成并返回名片卡片图片]
```

#### 搜索流程
```
用户：搜索张三

机器人：[返回名片卡片图片]

用户：搜索某某公司

机器人：[返回公司信息 + 联系人列表]
```

## 7. 部署架构

### 7.1 Docker容器设计

```
群晖 DSM
└── Docker
    └── Container: business-card-app
        ├── 端口: 8000 (内部，不对外暴露)
        ├── 环境变量:
        │   ├── WECHAT_CORP_ID
        │   ├── WECHAT_SECRET
        │   ├── WECHAT_AGENT_ID
        │   └── DATA_DIR=/data
        └── Volume挂载:
            ├── /data/db → 群晖 /docker/business-card/data/db
            ├── /data/photos → 群晖 /docker/business-card/data/photos
            └── /data/avatars → 群晖 /docker/business-card/data/avatars
```

### 7.2 目录结构

```
business-card-system/

│   ├── __init__.py

│   ├── card_generator.py       # 名片图片生成
│   ├── handlers.py             # 消息处理逻辑
│   └── state_machine.py        # 录入状态机
├── data/
│   ├── db/
│   │   └── business_cards.db   # SQLite数据库文件
│   ├── photos/                 # 名片照片
```

## 9. 后续升级方向（方案三模块化架构）

为了支持后续平滑升级，系统将设计为模块化：

```
business-card-system/
├── core/                      # 核心模块（不变）
│   ├── database.py
│   └── models.py
├── modules/
│   ├── wechat_bot/            # 企业微信模块
│   ├── ocr/                   # OCR模块（可插拔）
│   │   ├── easyocr.py
│   │   └── base.py
│   ├── search/                # 搜索模块（可插拔）
│   │   ├── simple_search.py
│   │   └── ai_search.py
│   └── face_recognition/      # 人脸识别模块（可选）
└── plugins/                   # 插件目录
```
