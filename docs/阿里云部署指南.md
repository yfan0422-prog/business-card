## 前置准备

### 1.1 需要准备
- ✅ 阿里云轻量服务器（推荐配置：2核4G，Ubuntu 22.04）
- ✅ 域名 `ai-codify.com`（已在阿里云或其他注册商购买）
- ✅ 本地电脑已安装 Git

### 1.2 推荐服务器配置
| 配置项 | 最低配置 | 推荐配置 |
|--------|---------|---------|
| CPU    | 1核     | 2核     |
| 内存   | 2GB     | 4GB     |
| 硬盘   | 40GB    | 60GB+   |
| 系统   | Ubuntu 20.04+ | Ubuntu 22.04 |

## 服务器初始配置

### 2.1 连接服务器
使用 SSH 连接到您的阿里云服务器：
```bash
ssh root@<服务器IP>
```

### 2.2 更新系统
```bash
apt update && apt upgrade -y
```

### 2.3 安装 Docker 和 Docker Compose
```bash
# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# 启动 Docker
systemctl start docker
systemctl enable docker

# 安装 Docker Compose
apt install -y docker-compose-plugin

# 验证安装
docker --version
docker compose version
```

### 2.4 配置防火墙
```bash
# 开放 HTTP 和 HTTPS 端口
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 22/tcp  # SSH 端口，确保不被关闭！
ufw enable
```

### 3.1 登录阿里云控制台
1. 访问：https://dns.console.aliyun.com/
2. 找到 `ai-codify.com` 域名

|---------|---------|-------|-----|
| A       | @       | 您的服务器IP | 600 |
| A       | www     | 您的服务器IP | 600 |

## 首次部署

### 4.1 克隆项目到服务器
```bash
cd /opt
git clone <您的git仓库地址> business-card
cd business-card
```

如果还没有 Git 仓库，可以从本地上传：
```bash
# 在本地电脑运行：
scp -r /path/to/business-card root@<服务器IP>:/opt/
```

### 4.2 修改域名配置（如需要）
如果域名不是 `ai-codify.com`，编辑 `Caddyfile`：
```bash
nano Caddyfile
```
将第一行修改为您的域名。

### 4.3 运行部署脚本
```bash
chmod +x deploy.sh
./deploy.sh
```

首次部署会自动：
- 构建 Docker 镜像
- 申请免费 HTTPS 证书（自动续期）
- 启动服务

### 4.4 验证部署
等待 1-2 分钟，访问：
- https://ai-codify.com

应该能看到名片管理系统了！

## 日常更新

### 5.1 更新流程（非常简单！）

当您在本地修改了代码并提交后：

```bash
# 1. 本地提交代码
git add .
git commit -m "描述您的修改"
git push

# 2. SSH 连接服务器
ssh root@ai-codify.com

# 3. 进入项目目录
cd /opt/business-card

# 4. 一键更新！
./deploy.sh
```

就这么简单！`deploy.sh` 会自动：
- 拉取最新代码
- 备份当前数据
- 重新构建并重启服务

### 5.2 本地开发后部署建议
```bash
# 本地开发完成后
git status              # 检查修改
git add .               # 添加修改
git commit -m "xxx"     # 提交
git push                # 推送到远程

# 服务器端更新
./deploy.sh             # 一键部署
```

## 数据备份与恢复

### 6.1 自动备份
建议设置定时任务每天自动备份：

```bash
# 编辑定时任务
crontab -e

# 添加一行（每天凌晨2点备份）
0 2 * * * cd /opt/business-card && ./backup.sh >> /var/log/backup.log 2>&1
```

### 6.2 手动备份
随时可以手动备份：
```bash
./backup.sh
```

备份文件保存在 `backups/` 目录。

### 6.3 数据恢复
如果需要恢复备份：
```bash
# 1. 停止服务
docker-compose -f docker-compose.prod.yml down

# 2. 解压备份
tar -xzf backups/backup_xxxxxxxx_xxxxxx.tar.gz

# 3. 重新启动
./deploy.sh
```

## 常用命令

### 查看服务状态
```bash
docker-compose -f docker-compose.prod.yml ps
```

### 查看日志
```bash
# 查看所有日志
docker-compose -f docker-compose.prod.yml logs -f

# 只看应用日志
docker-compose -f docker-compose.prod.yml logs -f app
```

### 重启服务
```bash
docker-compose -f docker-compose.prod.yml restart
```

### 停止服务
```bash
docker-compose -f docker-compose.prod.yml stop
```

### 启动服务
```bash
docker-compose -f docker-compose.prod.yml start
```

### 更新 Docker 镜像
```bash
docker-compose -f docker-compose.prod.yml pull
docker-compose -f docker-compose.prod.yml up -d
```

## 故障排查

### 问题：访问网站提示不安全
**原因**：HTTPS 证书还没申请好
**解决**：等待 2-5 分钟，Caddy 会自动申请证书

### 问题：无法访问网站
**检查步骤**：
1. 检查域名解析是否生效：`ping ai-codify.com`
2. 检查服务状态：`docker-compose -f docker-compose.prod.yml ps`
3. 查看日志：`docker-compose -f docker-compose.prod.yml logs`

### 问题：Docker 命令需要 sudo
**解决**：将当前用户加入 docker 组
```bash
usermod -aG docker $USER
# 重新登录后生效
```

## 安全建议

1. **修改 SSH 端口**（可选）：从 22 改为其他端口
2. **禁用 root 密码登录**：使用 SSH Key
3. **定期更新系统**：`apt update && apt upgrade`
4. **定期备份数据**：已配置定时任务自动备份
